# Heatmap Plotter Catalog

This internal catalog preserves the raw plotter-family inventory that used to live under `docs/`. Public users should use [docs/README_heatmaps.md](/media/am/AM/logit-diff-lens/docs/README_heatmaps.md), which is now the single public plotting guide.

The legacy heatmap modules currently inventoried are:

- `adl_plotter.py`
- `jaccard_heatmap_plotter.py`
- `ldl_plotter.py`
- `logit_lens_plotter.py`
- `logitdiff_gen_paper_plotter.py`
- `logitdiff_gen_paper_plotter_selected_rows.py`
- `logitdiff_gen_plotter.py`
- `logitdiff_pair_heatmap_plotter.py`
- `prompt_lens_heatmap_plotter.py`

This file is internal-only so the repo can keep a low-level plotter inventory without splitting the public documentation surface into multiple plotting pages.
